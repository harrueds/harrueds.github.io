### 6. Justification for Not Using CI/CD

Although GitHub Pages supports CI/CD, in this project **it is not necessary** because:

- The site is **completely static** (pure HTML/CSS).  
- GitHub Pages performs **automatic deployment** on `git push`.  
- No compilation or automated file validation is required.  
- Implementing CI/CD would add unnecessary complexity without practical benefits.

> Note: If frameworks, site generators, or validations are incorporated in the future, then a CI/CD workflow could be implemented.
